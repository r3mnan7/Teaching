# Scanner Rules

← Previous: [[00 Desktop Getting Started|Desktop Getting Started]]
Next: [[00 Features|Features]] →

ZAP supports both [[05 Active Scan|active]] and [[20 Passive Scan|passive]] scanning rules.

All rules are contained in [[01 Add-ons|add-ons]] so that they can be updated quickly and easily.

By default ZAP ships with just the ‘Release’ status rules, but you can install ‘Beta’ and ‘Alpha’ status rules via the [Manage Add-ons dialog](https://www.zaproxy.org/docs/desktop/ui/dialogs/manageaddons/).

[[22 Scan Policy|Scan Policies]] define which rules run and how they run.

You can have as many scan policies as you like to cover different situations.

To manage scan policies open the [Scan Policy Manager dialog](https://www.zaproxy.org/docs/desktop/ui/dialogs/scanpolicymgr/)
