# Structural Modifiers

Part of [[00 Features|Features]]
← Previous: [[28 Statistics|Statistics]]
Next: [[30 Structural Parameters|Structural Parameters]] →

Structural Modifiers are controls which change how ZAP represents the structure of the application.

The [[26 Sites Tree]] is ZAP’s representation of the application.

If it is not a good representation of the structure then ZAP will not be able to attack the application effectively.

There are currently 2 types of Structural Modifiers:

- [[13 Data Driven Content]] which identify URL paths that represent data
- [[30 Structural Parameters]] which identify parameters that represent application structure instead of user data

Structural Modifiers can only be applied to [[11 Contexts]].
