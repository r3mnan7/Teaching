# Passive Scan

Part of [[00 Features|Features]]
← Previous: [[19 Notes|Notes]]
Next: [[21 Software Bill of Materials|Software Bill of Materials]] →

The passive scanner is provided by the [Passive Scanner add-on](https://www.zaproxy.org/docs/desktop/addons/passive-scanner/), which allows to passively scan messages (e.g. HTTP, WebSocket) proxied/sent through/by ZAP.
