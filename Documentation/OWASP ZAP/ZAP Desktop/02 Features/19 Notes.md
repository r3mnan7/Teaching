# Notes

Part of [[00 Features|Features]]
← Previous: [[18 Modes|Modes]]
Next: [[20 Passive Scan|Passive Scan]] →

A note is any text that you wish to associate with a request.

For example you could use notes to record details of extra tests that you need to perform on a request.

Notes are added and changed using the [Add Note dialog](https://www.zaproxy.org/docs/desktop/ui/dialogs/addnote/).

Notes are flagged in the [History tab](https://www.zaproxy.org/docs/desktop/ui/tabs/history/) with the ![[desk-features-notes-172.png]] icon.
